Project context

As Service Desk Manager at Cox Automotive, I see first-hand how much time is spent on requests that could be handled through self-service. This project replicates that problem using a fictional company — Crestline Technologies — as the canvas, letting me build a production-style portal without touching live systems.

The portal covers the four most common request types on any service desk: password resets, new starter provisioning, hardware requests, and themed portal access — each with its own workflow, approvals, and automated fulfilment tasks.
