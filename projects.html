Crestline Kit Tracker Complete
Data Modelling ACLs Import Sets CMDB / CSDM Security Center

A loaned equipment tracker built as a five-phase CSA exam prep project, deliberately targeting my weakest exam areas: data modelling, ACL configuration, and CMDB/CSDM ownership. Covers table extension, table and field-level ACLs (including script-based conditions), import sets with coalesce behaviour, and CI relationships tied back to Incident.

What I built
  • Custom schema — standalone and Task-extended tables
  • Table and field-level ACLs, impersonation-tested
  • Script-based ACL condition
  • Import set with mismatched headers and coalesce
  • CMDB CIs related via Runs on::Runs, linked to Incident
Skills developed
  • Data model design and table extension
  • ACL logic and role-based security
  • Transform maps and coalesce behaviour
  • CI Class Manager and CI relationships
  • Shared Responsibility Model
Built and tested real evidence against the three CSA exam areas furthest from my day-to-day ITSM operations work — not just studied, but demonstrably working on a live PDI.
